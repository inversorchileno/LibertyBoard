# LibertyBoard, compilación 16

**Doble pizarra**

- Modo → Doble pizarra: dos documentos lado a lado (dos PDF, o un PDF y una pizarra de notas), con línea divisoria movible.
- Preferencias → Paleta del lápiz: arriba, abajo, izquierda o derecha.
- Formas con el color de borde y relleno en su ícono.

---
Descarga `LibertyBoard-windows.zip`, descomprímelo y abre `LibertyBoard.exe`, o actualiza desde **Acerca → Actualización**.
