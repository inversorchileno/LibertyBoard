La palette d’outils

Chaque bouton choisit un outil, et ses options apparaissent dans la barre du haut.

  • Dans le menu Personnaliser, choisissez les boutons visibles, sur le tableau et sur le bureau.
  • Avec Personnaliser → Déplacer les éléments, changez leur ordre en les faisant glisser.
  • Un bouton retiré garde son outil dans le menu Outils.
  • Chaque outil a un raccourci clavier : voyez-les et changez-les dans À propos → Raccourcis.
Les outils qui font deux choses, comme Projecteur / Loupe, passent de l’une à l’autre dans leur barre d’options.
