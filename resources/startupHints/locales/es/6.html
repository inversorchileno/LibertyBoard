Modo Web

El modo Web es un navegador interno con algunas funciones extra respecto de uno normal.

Usar el navegador interno

Con el navegador interno puedes navegar por Internet sin achicar ni cerrar LibertyBoard, con funciones extra para capturar parte de la pantalla o crear aplicaciones a partir de sitios, ¡y agregarlas a la pizarra!

Crear una aplicación

Puedes crear una aplicación a partir de cualquier sitio, para agregarla a la pizarra y usarla como las aplicaciones incluidas.

Para hacerlo, ve al sitio que quieres capturar, haz clic en y confirma con «Crear una aplicación».

Cuando se crea una aplicación, se guarda sola en la biblioteca de LibertyBoard, para usarla en cualquier documento. La encontrarás en la carpeta de aplicaciones, dentro de una llamada «Web».

Usar un navegador externo

También puedes usar un navegador externo, marcando la opción en las preferencias. Entonces el icono Web abrirá tu navegador favorito en el modo Escritorio.

Con un navegador externo también puedes crear aplicaciones a partir de un sitio: copia la dirección de la barra del navegador, vuelve a la pizarra y pégala.
